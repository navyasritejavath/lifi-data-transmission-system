  3. Simulate LED light pulses.

ABOUT THE PROJECT

What is Li-Fi?

Li-Fi stands for Light Fidelity. It is a wireless communication technology that can use light to transmit data. In this project, JavaScript simulates the encoding, light pulses, and decoding process without physical hardware.
